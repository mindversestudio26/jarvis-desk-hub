# AI and voice feasibility — researched 16 October 2026

Hosting a website supplies compute/storage and HTTP endpoints; it does not supply a language model, model entitlement, microphone transcription or a private route into a PC. Existing prepaid hosting can remove new backend hosting spend, but future renewal is still an existing cost.

**Recommendation:** First deploy reviewed shared-data functionality with AI disabled. Choose a free-quota provider only after the owner decides what text may leave the system. Keep private memory out of prompts unless explicitly selected. Use a small multilingual local model through Tailscale for private experiments when a computer is awake; do not make backend availability depend on it. No current option establishes unlimited, private, high-quality, always-on bilingual speech reasoning at zero additional cost.

## Speech and Siri

Browser `SpeechRecognition` is not universally supported and can use server-side recognition. Setting `lang='ne-NP'` requests Nepali; it does not prove availability or quality. Offline recognition must not be promised. The prototype feature-detects the API, starts only from a click, captures one transcript, requires a separate Apply action and falls back to typing/keyboard dictation. It has not recorded audio or tested real Nepali speech. [Recognition documentation](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)

Browser `speechSynthesis` uses available voices. The prototype selects an installed voice matching English/Nepali and reports unavailable rather than pretending a Nepali voice exists. Installed voices, network dependence and accent quality require physical-device verification; speech synthesis is not language-model reasoning. [Synthesis documentation](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)

Siri can run a named Shortcut on iPhone/iPad/Mac. Begin with a Shortcut that captures text and opens the authenticated Jarvis command form; never put a master key/password in a URL or shared Shortcut. A future direct write integration needs a separately scoped, revocable device grant and a review/confirmation step. The present strict-Origin cookie API intentionally does not accept arbitrary unauthenticated Shortcuts POSTs. Siri's own language support is independent of the model's Nepali text support. [Apple Shortcuts/Siri](https://support.apple.com/guide/shortcuts/use-siri-to-run-shortcuts-apd07c25bb38/ios), [URL scheme](https://support.apple.com/guide/shortcuts/run-a-shortcut-from-a-url-apd624386f42/ios)

The implemented English/Nepali command grammar is deterministic: “add task …”, “काम थप …”, “list tasks”, “कामहरू देखाऊ”. Unicode storage and typed Nepali commands are tested. Natural back-and-forth conversation, translation quality, actual microphone recognition and spoken Nepali are **not** validated or represented as working AI.
