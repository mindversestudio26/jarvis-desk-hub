        Trusted PC monitoring

        Optional: connect the read-only companion over Tailscale HTTPS. Credentials stay in memory and are cleared on reload. A failed connection means unreachable, not necessarily powered off.

        Local data

        Tasks, events and alarms stay in this Safari installation. Keep a JSON backup for recovery.

        Install on iPad

        Open the live site in Safari → Share → Add to Home Screen → Add. Open JANGE once online so offline files can be saved. The home-screen name and icon update when you add it again.

        Assistant

        Voice activation (“Hey Jange”) is not enabled. It needs a reliable on-device wake-word engine and will be added separately; JANGE never listens in the background today.
